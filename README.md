# 吃啥饭 · 校园食堂评价系统 🍚

一个基于 Spring Boot 的校园食堂菜品评价 Web 应用。同学可以浏览食堂菜品、查看人气榜、给菜品打分并晒图评价，帮助大家"避开雷区、发现好菜"。

## 功能特性

- 用户注册 / 登录 / 退出（密码 BCrypt 加密存储，Session 管理登录态）
- 菜品列表 + 人气榜 Top10（按平均分排序）
- 菜品详情：菜品信息 + 评价列表 + 平均分展示
- 提交评价：星级打分、文字点评、上传晒图
- 防重复评价（业务层拦截 + 数据库唯一索引兜底）
- 平均分自动重算
- Excel 批量导入菜品（EasyExcel）
- 管理员后台（菜品增删改）
- 响应式 UI，适配手机端

## 技术栈

| 分类 | 技术 |
|------|------|
| 框架 | Spring Boot 3.5 |
| 持久层 | MyBatis-Plus 3.5 |
| 模板引擎 | Thymeleaf |
| 数据库 | MySQL 8 |
| 工具库 | Lombok、EasyExcel、Spring Security Crypto（仅用 BCrypt） |
| 构建 | Maven |

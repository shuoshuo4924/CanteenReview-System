# ==========================================================
# 评论过滤词库
#
# 规则：
#   1. 一行一个词，中文 / 英文 / 数字均可，匹配时不区分大小写
#   2. 以 # 开头是注释，空行会被忽略
#   3. 建议只收 2 字及以上的词：单字太容易误伤正常表达
#   4. 程序匹配前会自动忽略空格和常见符号（* - _ . 等），
#      并统一全角半角，所以"加*微*信""加 微 信"同样会被拦住
#   5. 改完这个文件重启应用即可生效，不需要改代码
#
# 选词原则（防止误伤）：
#   - 只收不太可能出现在正常句子里的组合。例如"妈的"会命中
#     "妈妈的菜真好吃"，"我操"会命中"我操作了一下"，这类不要收
#   - "废物""智障"等虽可能出现在自嘲或医学描述里，但评论区概率低，
#     先收进去；如果发现误伤，直接删掉对应那一行即可
# ==========================================================
